# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-24

### Added

- Side panel with five sections: session, now, files this session, commands and system.
- Session: model, repository and branch, unpushed commits, uncommitted files,
  context window, 5-hour and weekly usage limits, session time and estimated cost.
- Files grouped by folder and marked as created, edited, read or searched.
- The last five shell commands, with failed ones in red. Keys and tokens in them are masked.
- Disk, RAM and CPU on macOS.
- English and Spanish, chosen with the `language` option.
- `/sidepanel` command to open the panel.
